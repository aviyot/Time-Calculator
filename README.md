# Time Sum Calculator

A Next.js calculator for adding durations and applying multipliers.

## Getting started

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run build` and
`npm start` for a production build, or `npm test` to run the calculation tests.

On Windows PowerShell, use `npm.cmd` instead of `npm` if the execution policy
blocks `npm.ps1` (for example, `npm.cmd run dev`).

The Next.js app is in `app/` and uses the existing `style.css`. The original
`index.html` and `main.js` are retained as the pre-migration version.
